# diptype — универсальный скилл генерации дипломных материалов

Этот скилл описывает, как обрабатывать запрос пользователя из чата diptype: взять
приложенные документы и промпт, сгенерировать нужные файлы и при необходимости
загрузить их в репозиторий пользователя на GitHub.

## Поддерживаемые типы (kind)

| kind         | Что создаётся                          | Формат файлов        |
|--------------|----------------------------------------|----------------------|
| `diploma`    | Дипломная работа                       | `diploma.md`         |
| `presentation` | Презентация по дипломной работе      | `presentation.md`    |
| `website`    | Сайт-визитка по дипломной работе       | `index.html`         |
| `speech`     | Защитная речь к диплому                | `speech.md`          |

## Алгоритм

1. **Определи тип запроса** (`kind`) из контекста. По умолчанию — `diploma`.
2. **Собери входные данные**: текст промпта + извлечённый текст приложенных файлов
   (txt/md/csv/json читаются как есть; для docx/pdf используется имя и краткое описание).
3. **Сгенерируй контент** академическим стилем на русском языке:
   - Диплом: введение (актуальность, цель, задачи), 2–3 главы, заключение, список литературы.
   - Презентация: 8–12 слайдов (титульный, цель/задачи, актуальность, методы, результаты, выводы).
   - Сайт: одностраничный `index.html` в сине-белой палитре (#2563eb / #ffffff), без неона, шрифт Arial/Montserrat.
   - Речь: 3–5 минут на чтение, с обращением к комиссии и акцентом на результатах.
4. **Верни результат строго в JSON**:
   ```json
   {
     "title": "Короткий заголовок",
     "files": [{ "path": "diploma.md", "content": "..." }]
   }
   ```
   Без текста вне JSON и без markdown-ограждений.
5. **Загрузка в GitHub (опционально)**: если пользователь указал репозиторий, загрузи
   каждый файл через GitHub Contents API (`PUT /repos/{owner}/{repo}/contents/{path}`),
   предварительно получив `sha` существующего файла для обновления.

## Ограничения подписки

- `diploma` — первые `FREE_REQUEST_LIMIT` (по умолчанию 3) запросов бесплатны, далее по подписке Pro.
- `presentation`, `website`, `speech` — только по подписке Pro.

Серверная реализация этого скилла находится в `server/src/services/anthropic.js`
(генерация) и `server/src/services/github.js` (загрузка в репозиторий).
